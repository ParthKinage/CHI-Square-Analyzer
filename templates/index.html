Theory

Understanding the Chi-Square Goodness-of-Fit Test

📐

What is χ² Test?

The Chi-Square Goodness-of-Fit test determines whether observed sample frequencies differ significantly from expected theoretical frequencies. It's a non-parametric test used when data is categorical.

🎯

Hypotheses

H₀ (Null): Observed data follows the expected distribution.
H₁ (Alternative): Observed data does NOT follow the expected distribution.

📊

Test Statistic

χ² = Σ (Oi − Ei)² / Ei

Degrees of freedom: df = k − 1, where k = number of categories.

⚖️

Decision Rule

At significance level α = 0.05:
If χ² > χ²critical → Reject H₀
If χ² ≤ χ²critical → Fail to reject H₀

⚠️

Assumptions

1. Data must be categorical (nominal/ordinal)
2. Observations must be independent
3. Expected frequency for each cell ≥ 5
4. Sample is randomly drawn

🔬

Applications

• Testing if a die is fair
• Genetic ratio verification (Mendel's experiments)
• Survey response distributions
• Quality control in manufacturing
